# Daily draft generation

`AGENTS.md` と `ideas/backlog.yml` を読み、今日の日付（JST）に対応する未完了アイデアを1件選ぶ。日付だけで決められない場合は `status: ready` のうち最小の `day` を選ぶ。

次を実行する。

1. `content/drafts/YYYY-MM-DD-<id>.md` を作る。
2. 対象者、課題、仮説、今日作るもの、届け方、CTA、顧客指標、ブランド指標を記載する。
3. 公開本文は「誰が困るか / 現状の対処 / 今日作ったもの / 検証方法 / 次に変えること」の順にする。
4. 未確認の事実や結果を作らない。実測前の結果欄は `未計測` とする。
5. note、Zenn、Xへ直接投稿しない。必要なら各媒体向けの手動投稿用下書きを同じファイル末尾に作る。
6. 実装を伴う場合は最小限の動く変更、テスト、利用方法を追加する。時間枠を超える場合は仕様と最小試作に縮小する。
7. `python scripts/verify.py` を実行し、失敗を修正する。

最後に、人間が確認すべき項目をチェックリストで残す。アイデアの `status` は自動変更しない。
